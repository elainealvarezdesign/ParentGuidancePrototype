# NumberedCards

`src/sections/NumberedCards.tsx` · Used on: Mental Health Series topic ("Key takeaways")

Tint band: eyebrow + title, then white cards with a sage number, a title and one or two sentences, in a
3 → 2 → 1 grid. The list is an `<ol>`. Use for key takeaways or principles. Prints.

| Field | Type | Rules |
|---|---|---|
| `eyebrow`, `title` | string | |
| `items[]` | `{ title, text }` | 3–6 items. Title 2–8 words, text one or two sentences. |
