# CrisisLineBanner

`src/sections/CrisisLineBanner.tsx` · Used on: Get Help

Navy card with the crisis line logo and three direct actions: Call (`tel:`), Text (`sms:`) and Visit
Website (new tab). Use on Get Help and anywhere a page discusses risk.

| Field | Type | Rules |
|---|---|---|
| `logo` | `Media` | The line's logo, alt = its name. |
| `title` | string | 2–4 words ("Need Help Now?"). |
| `body` | string | One line. |
| `number` | string | Digits only ("988"). |
| `website` | URL | |

Crisis copy and numbers need clinical review before any change.
