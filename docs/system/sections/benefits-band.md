# BenefitsBand

`src/sections/BenefitsBand.tsx` · Used on: Parent Coaching

Navy band right after the hero with 3–4 short benefits: icon (sage), title, one line. 4 in a row on
desktop, 2×2 on tablet, stacked on mobile.

| Field | Type | Rules |
|---|---|---|
| `items[].icon` | `message`, `roadmap`, `privacy`, `calendar` | Add icons to `benefitIcons` in the section. |
| `items[].title` | string | 2–6 words. |
| `items[].body` | string | Up to ~80 characters. |
