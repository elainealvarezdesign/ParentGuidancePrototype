# IconCtaBanner

`src/sections/IconCtaBanner.tsx` · Used on: Get Help ("Not sure which resource is right for you?")

Rounded sage box inside another section's column: icon circle, question-style title, one sentence, one
inverse button. A `cta` without `to`/`href` renders a button with no destination yet (open item).

| Field | Type | Rules |

| `title` | string | Up to ~45 characters. |
| `body` | string | One sentence. |
