# PrevNextNav

`src/components/patterns/PrevNextNav.tsx`

"Previous / Next" links at the end of a detail page. `<nav aria-label>` with `rel="prev"`/`rel="next"`
links showing the neighbor's title (truncated). An empty side keeps the other aligned.

Props: `prev?`, `next?` (`{ title, to }`), `label` ("More answers").
