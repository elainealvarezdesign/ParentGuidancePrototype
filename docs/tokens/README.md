# Design tokens

[`parent-guidance.tokens.json`](./parent-guidance.tokens.json) holds every variable of the Figma library
[Design system - PG](https://www.figma.com/design/mWOJYdAxkKGj0bWSO2ptGj/Design-system---PG) (464 tokens) in the
[W3C Design Tokens](https://www.designtokens.org/) format, ready for Style Dictionary, Tokens Studio or any
tool that reads `$type` / `$value`.

- **Aliases are kept as references** (`"{Primitive Colors.Brand Color.Slate.Slate Base}"`), so changing a
  primitive updates every semantic token that points to it. All references resolve.
- **Layers:** `Primitive Colors` and `Primitive: Unit Scale` hold raw values; `Semantic Colors`,
  `Semantic: Color Roles`, the category/event/content-type colors, spacing, radius, sizing and typography
  point to them.
- **Modes:** `Typography` has four modes (Desktop Large, Desktop Regular, Tablet, Mobile). `$value` is the
  Desktop Regular value and every mode is listed under `$extensions["figma.modes"]`. Mobile matches the code
  below Tailwind `md` (768px); the other three match `md` and up.
- **Typography:** `Typography.Code Scale.*` is the scale the prototype uses (`display`, `h1` … `eyebrow`).
  `Typography.Font.Heading.*` are the larger Figma heading styles (H1 48px … H5 16px) kept for design work.
- **Motion:** durations and curves match `tokens.css` (150 / 220 / 350 / 550 ms; brand curve
  `[0.25, 0.46, 0.45, 0.94]`, open/close curve `[0.65, 0, 0.35, 1]`).

The JSON is generated by [`build-tokens.py`](./build-tokens.py) (`python3 docs/tokens/build-tokens.py`), which
also checks that every reference resolves. When a Figma variable changes, update the script and run it again.
